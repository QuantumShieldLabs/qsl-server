# Start here

- **Understand the component:** [README.md](README.md).
- **Inspect configuration and visibility:** [configuration guide](docs/CONFIGURATION.md).
- **Review validation:** [CI workflow](.github/workflows/ci.yml) and [traceability](TRACEABILITY.md).
- **Propose a change:** [CONTRIBUTING.md](CONTRIBUTING.md).
- **Report a sensitive finding:** [SECURITY.md](SECURITY.md).

The relay stores and forwards client-protected frames and implements invitation endpoints. Review the current API and authority boundaries together; do not infer that the relay is metadata-blind or semantics-free.

QSL is research-stage and not production-ready. Use synthetic local experiments. Accepted component/protocol contracts and maintainer review govern changes; historical task files are not a public contribution prerequisite or a current launch instruction.
